SteaMidra v6.4.1

What's new:

* Modern Settings now includes backup buttons near the top.
* Settings Export now writes a JSON backup without saved secrets, making it safer to share or store.
* Settings Import now reloads the visible settings immediately after applying the backup file.
* Older-version picker can now import one or more saved SteamDB depot pages into the selectable history list.
* Saved SteamDB depot page import helps when the live history list is blocked, unavailable, or empty, as long as you already saved the depot pages.
* Docs updated to match the current online-fix flow and the new Settings backup UI.
* online-fix remains browser-open only. Downloads and login are handled on the online-fix website, not inside SteaMidra.

Full detailed changelog is in CHANGELOG.md
